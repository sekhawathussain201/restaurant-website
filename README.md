## ⚡ Supabase Setup (1 Minute)

Your Supabase project URL and anon public key are already configured in `src/lib/supabase.js`.

To create the `orders` table in your Supabase project:
1. Go to your Supabase Dashboard: [https://supabase.com/dashboard/project/kpdcqcdrtoagkqiamyux/sql/new](https://supabase.com/dashboard/project/kpdcqcdrtoagkqiamyux/sql/new)
2. Paste the following SQL script:

```sql
-- 1. Create the orders table
CREATE TABLE IF NOT EXISTS public.orders (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    customer_name TEXT NOT NULL,
    phone TEXT NOT NULL,
    address TEXT NOT NULL,
    dishes TEXT NOT NULL,
    items JSONB DEFAULT '[]'::jsonb,
    total_amount NUMERIC NOT NULL,
    status TEXT NOT NULL DEFAULT 'Pending' CHECK (status IN ('Pending', 'Preparing', 'Delivered')),
    notes TEXT DEFAULT '',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- 2. Enable Row Level Security (RLS)
ALTER TABLE public.orders ENABLE ROW LEVEL SECURITY;

-- 3. Policy: Allow customers to place orders (Insert)
DROP POLICY IF EXISTS "Allow anon to insert orders" ON public.orders;
CREATE POLICY "Allow anon to insert orders" ON public.orders 
FOR INSERT TO anon, authenticated WITH CHECK (true);

-- 4. Policy: Allow reading orders
DROP POLICY IF EXISTS "Allow public to view orders" ON public.orders;
CREATE POLICY "Allow public to view orders" ON public.orders 
FOR SELECT TO anon, authenticated USING (true);

-- 5. Policy: Allow updating order status (Part B)
DROP POLICY IF EXISTS "Allow status update" ON public.orders;
CREATE POLICY "Allow status update" ON public.orders 
FOR UPDATE TO anon, authenticated USING (true) WITH CHECK (true);
```
3. Click **RUN**.
4. Go back to your website at [http://localhost:5173/](http://localhost:5173/) and click **"Supabase Setup"** in the top navigation to verify the green checkmark!

## ✉️ Gmail Order Delivery Verification (For Submission Screenshot)

Requirement 3 requires a screenshot of an order in your Gmail:
1. In the top navigation bar or inside the Order Form, you can see the **"Recipient Gmail"** box.
2. Enter your personal Gmail address (e.g. `yourname@gmail.com`).
3. Fill out the order form and click **"Place Order"**.
4. Check your Gmail inbox (and Spam/Promotions folder just in case on first send).
5. Take a screenshot showing the order email with:
   - Customer Name
   - Phone & Delivery Address
   - Dish Breakdown & Quantities
   - Grand Total
   - Status: Pending
