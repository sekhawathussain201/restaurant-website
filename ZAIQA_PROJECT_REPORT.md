## 📌 1. Restaurant Website (`restaurant-website`)

### ✨ Features & Architecture
* **Framework:** React + Vite + Tailwind CSS + Lucide Icons
* **Multi-Page Navigation:**
  * **Home (`/`):** Hero section, chef's specials, royal heritage banner, CTA buttons.
  * **Menu (`/menu`):** Categorized dishes (Biryani, Charcoal BBQ, Shinwari Karahi, Desserts & Beverages).
  * **Order Now (`/order`):** Dynamic cart, quantity controls, express delivery forms.
  * **Track Order (`/track`):** Real-time order tracking using unique Reference IDs with live database integration.
  * **Customer Reviews (`/reviews`):** Verified guest reviews with interactive star ratings and submission modal.
  * **Contact & Location (`/contact`):** Karachi outlet timings, map directions, and customer support.
* **Database & Backend:** Supabase connected for live order storage and real-time status updates.
* **Responsive Layout:** Fully optimized across iPhone, iPad / Tablets, and Desktop screens.

## 🚀 5. How to Launch and Use

1. **Start Social Media Marketplace:**
   * Double-click `Start.cmd` in `Desktop/marketplace`.
   * Opens browser automatically at `http://localhost:4545`.
2. **View Library:**
   * Open the **Library** tab to preview all videos and pictures.
3. **Publish / Schedule Posts:**
   * Navigate to the **Post** tab, select any generated video or image, select TikTok or Instagram, and click Schedule!
